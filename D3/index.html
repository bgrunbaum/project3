Global-mean SST

Click any ocean cell on the map to see its yearly SST. Drag the shaded window to move it through time.

MIROC6 historical (r5i1p1f1), sea-surface temperature tos, annual means, 2°×2° cells. Each frame fits a least-squares line to the annual SST of every ocean cell over the selected window; the slider moves the window's last year. The global mean is weighted by cos(latitude). The color scale is fixed while the window slides, and changes only with window length, because shorter windows have larger (noisier) trends. The model grid is not a regular latitude/longitude grid north of 63°N, so the Arctic is not shown.
